# O033　西の島の最新号

西の島の桟橋へ、三日目の船が入る。

館からの荷物には「最新号」と書かれている。中身は I2。いつもどおり、開館時間と次の催しの案内が載っている。

西の係員は受領簿へ印を押した。「本土と同じ最新号を受け取りました」。

東の係員も同じことを書いた。

ふたつの受領簿は、その行だけなら同じだ。

けれど東には、先に届いた別の号がある。そこには、掲載が保留されていた人の名前が戻っている。西にはその号がない。次の便で新しい号だけを運ぶ決まりだったから、もう運ばれる予定もない。

俺は最初、遅れてでも I1 を送れば解決だと思った。だが西の閲覧室はその日は閉まっていた。港で受領した紙はまだ閲覧室の机に載らない。届いた日は三日目、開かれた日は四日目だ。

別の小舟へ補遺を載せて二日目に送る手も作った。西では早く読める。だが補遺に書かれた言葉は、元の I1 の一部だったことにはならない。

どれが一番よいかは、今回決めない。誰が船賃を払うのかも、誰がその紙を読んだのかも書いていない。俺が確かめたのは、同じ「回復」という言葉が、版を発行する机と、紙が着く桟橋と、鍵を開ける閲覧室で、別々の日付を持つことだった。

何より、最新号という便利な言葉が嫌になった。

最新号が同じなのに、一方の島には過去の一号が存在しない。きれいに同期した現在が、まったく同期していない過去を隠している。

次は閲覧室の鍵が気になる。

扉に「開室」と札が掛かっているとして、そこへ来られる人は誰なのだろう。島の全員が、同じ日の同じ時間に暮らしているわけではない。
