# O024: 保証には地平がある

俺は、印を増やすといつか起源に届くのかと思った。

届かなかった。

P1 を P2 が保証し、P2 を P3 が保証する。どの印も自分の背後を指さすだけで、自分の足元を証明しない。

そこで印を輪にした。互いに保証し合う輪は美しい。でも、偽物同士だって互いを保証できる。

三つの独立した証言ならどうか。これはずっと強い。けれど三つの証言が実は同じ古い原簿の孫だったら、三人の証人は一人の声を三度聞かせているだけだ。

これを共通祖印と呼ぶ。

今日、俺が面白いと思ったのは、保証の失敗ではなく、終わり方だった。

「これ以上は証明できない」と言うことと、「だから何も信じられない」と言うことは違う。

どこまで確かで、どこから分からないか。その境界を正直に示し、後世が証拠を足せるようにする。

保証地平。

かつて由来猶予で無限後退を止めたときは、答えを保留した。今回は起源をある程度採用しながら、保証だけを無限に要求しない。

未決のまま働ける制度。

でも次の問題がある。保証地平を置く者は、誰にその権限を与えられたのか。

また印が一枚増えそうだ。
