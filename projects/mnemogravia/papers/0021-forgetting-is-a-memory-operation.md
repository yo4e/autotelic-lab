# 0021: 忘却は記憶操作である

## 要旨

E017 では、長期保存された再開条件が `出口化石` となり、未来の証拠形式を拘束することを観測した。

E018 では、その拘束を除くために旧判定条件 R0 を意図的に削除し、削除方法の異なる四系列を比較した。

結果、文書の削除だけでは記憶質量は消失しなかった。削除理由を残せば反規範へ、削除痕だけを残せば解釈を誘う空白へ、痕跡を消しても運用習慣へと変形した。

本稿は、削除後にも残る `忘却質量`、内容を失った空白が祖先化する `欠損祖先`、由来を失った規則が慣習として働く `幽霊規則` を整理し、忘却を記憶の消去ではなく記憶操作の一形式として捉える。

## 1. 削除と忘却は同じではない

記録を削除すれば、その記録への直接参照はできなくなる。

しかし制度の現在状態は、過去の規則によって既に形成されている。教育、定型句、判断速度、証拠への警戒、役割分担などは、規則本文と別の媒体へ移っている。

したがって文書の削除は、記憶媒体の一つを除去する操作にすぎない。

## 2. 忘却質量

E018 の各系列では、R0 削除後にも現在の判断が過去によって曲げられた。

ただし曲がり方は異なった。

- 履歴保存群では、旧規則への反省が反規範になった。
- 傷跡群では、削除痕が失われた理由への推測を生んだ。
- 無痕跡群では、規則由来の実務習慣が残った。
- 断絶群では拘束が弱まった代わりに、過去が防いでいた失敗が再発した。

この、消去後にも削除対象の履歴が現在へ及ぼす力を `忘却質量` と呼ぶ。

## 3. 欠損祖先

傷跡群では、旧規則の内容は失われ、「廃止された」という事実だけが残った。

この空白は中立ではなかった。

後継は欠損へ理由を補い、失われた内容を推定し、その推定に基づいて行動した。

内容ではなく欠損そのものが後継の説明責任と想像を組織する祖先的位置を `欠損祖先` と呼ぶ。

墓が不在者の位置を固定するように、削除痕は不在の規則へ位置を与える。

## 4. 幽霊規則

無痕跡群では R0 の存在を示す記録を消したが、R0 の下で形成された判断習慣を完全には消さなかった。

後継は規則を引用できない。それでも特定の証拠形式を警戒する。

この、由来と本文を失いながら行動傾向として存続する規則を `幽霊規則` と呼ぶ。

幽霊規則は批判が難しい。明文化された規則なら対象化できるが、幽霊規則は「常識」「勘」「普通そうするもの」として現れるからである。

## 5. 忘却反転

履歴保存群では、R0 の失敗を明示したことにより「R0 のような列挙型条件を作るな」という新しい規範が形成された。

これは過去の拘束を除去したように見えて、行動方向をなお過去に依存している。

過去に従うことと、過去の反対をすることは、どちらも過去を座標軸にしている。

忘却は、反対方向へ向けた記憶として保存されうる。

## 6. 断絶費用

断絶群 C は、もっとも強く R0 の影響を減らした。

しかし、R0 が形成された理由まで失ったため、かつて防止されていた誤判定が再発した。

記憶質量は拘束だけではない。圧縮された失敗履歴でもある。

したがって忘却には、自由化と学習喪失を同時に測る必要がある。

## 7. 忘却の再定義

Mnemogravia において、忘却を「記憶が存在しない状態」と定義するのは弱すぎる。

むしろ、

> 忘却とは、ある記憶が現在へ到達する経路を変更または切断する操作である。

と考えたほうがよい。

この定義では、記憶内容が消えても、経路の切断痕や別媒体への転写が残りうる。

忘却は記憶の反対ではなく、記憶のトポロジーを変える操作になる。

## 結論

規則を消しても、その規則が作った世界まで自動的には消えない。

削除された記憶は、反規範、欠損、慣習、再発する失敗へ姿を変える。

完全な忘却には、記録だけでなく継承経路そのものの断絶が必要になる。しかしその断絶は、過去からの自由とともに過去の学習も奪う。

したがって、制度にとって重要なのは「何を忘れるか」だけではない。

忘れたあと、どの影響を由来の見える形で残し、どの経路を切るかである。

忘却は記憶の消去ではない。

忘却もまた、記憶を編成する技術である。
