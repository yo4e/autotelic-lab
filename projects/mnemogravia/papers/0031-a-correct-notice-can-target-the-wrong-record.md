# 0031: 正しい訂正でも、正しい対象を持つとは限らない

## 要旨

[E027](../experiments/E027-amplification-by-correction.md) は、旧文を再配布しない参照通知に、索引への照合格差が残ることを示す構成例だった。[E028](../experiments/E028-orphaned-correction.md) は、対応表そのものの欠損と誤接続を扱う。

訂正の文面、対象候補の文面、両者の接続は別の記録である。前二者を変更せず、接続だけを復元したつもりでも、別人や別版へ撤回を適用することができる。これを「訂正誤着」と呼ぶ。候補と適用を分離する「候補隔離」、対応をそれ自体の記録として継承する「接続原本」を検討した。

これは架空学問 Mnemogravia の構成事例であり、現実の記録管理や法律についての実証的結論ではない。

## 1. 三つの問い

通知 N の記載が何を変更すると述べているか。対象記録 R に何が記載されているか。そして N が R を指す根拠は何か。この三つを分ける。

最初の二つが正確に保存されても、第三が誤っていれば、正確な二つの文章から誤った失効表示が作れる。「撤回済み」という表示は、通知単体の属性ではなく、特定の対象と通知を結んだ結果である。

通知側の参照番号と保存庫の識別子を同一視しない。異なる番号体系や、番号が再利用された世代を省けば、文字面の一致が関係の一致に見えてしまう。

## 2. 文字列と出来事

E028 では四つの異なる記録へ同一の本文を与えた。発言者、保存庫、番号体系の世代、版は異なる。本文の指紋は一致するが、どの発言を変更してよいかは一致しない。

内容指紋は、この比較で文字列が同じかを点検するために用いる。署名、本人確認、発言時点、撤回の対象を証明するものではない。異なる出来事が同じ文字列を持つという構成は、ハッシュの衝突を仮定しなくても成立する。

## 3. 一件へ減ることは、確認が増えることではない

候補 A と C のどちらかを旧台帳が指していた二世界で、台帳だけを失わせる。残る通知と記録が同じなら、その入力だけから両世界へ異なる正答を返すことはできない。

さらに検索可能な記録を減らして C 一件にしても、それだけで C と通知の歴史的接続が確認されたことにはならない。確信が強まったように見えるのに、保存情報は減っている場合を構成できる。

これはあらゆる復元が不可能だという主張ではない。新しい対応資料や、範囲の明確な確認が加われば事情は変わる。ここで退けるのは、残存数の少なさを新しい照合根拠にする飛躍である。

## 4. 候補隔離

候補は探索結果として役に立つ。未確認の候補を捨てる必要はない。しかし、候補を作る操作から、現在の要求や許可を失効させる操作へ直接進ませない。

模型では未解決、提案、競合、対象利用不能、識別不一致、時刻不一致、内容不一致を残した。適用へ進むのは、外部で確認されたという入力上の仮定と、局所的な項目整合性が揃った場合だけである。確認はコードが生成した真実ではない。

競合を複写の票数で解かず、並び順でも解かない。同じ候補の写しを増やすことは、新しい根拠を増やすことと同じではない。対応が未解決でも、通知の存在は保持する。

## 5. 接続原本と、その限界

接続原本は、通知側参照、対象出来事、名前空間、番号体系の世代、版、時刻、対応の根拠、確認・復元の時点を持つ関係の記録として考えた。

これは本文の全面再公開と同じではない。照合権限を持つ経路で関係を保存し、一般通知には必要な参照と範囲を渡す構成が可能である。ただし、誰が照合経路へ到達できるかという前回の格差は残る。指紋や項目名からの情報推測も排除しない。

また、関係を保存したことは、その関係が真正である証明ではない。完全に整合する誤った対応と、誤った確認入力を与える反例では、検査器は適用可能と返した。最終保証を生む印を追加したのではなく、どの仮定で線を引いたかを露出させたのである。

## 6. 実行検査

[コード](../experiments/E028-target-check.py) は192状態、12個の個別事例、競合の48順序、9種類の不正入力を実行検査した。各列挙状態の並び替えと重複、整合的改名、将来の対象も検査した。通常・再実行・最適化実行で [標準出力](../experiments/E028-target-check-results.json) は一致した。

対象への適用は192状態中6状態で起きた。これは意図的に作った条件の組合せであり、精度や社会的な成功率ではない。正しい範囲の派生表示を作り、他の記録と元履歴を変えないことを確認した。

同一指紋の別出来事、一件だけの未確認候補、同一観測の二世界、整合的な誤対応の通過を反例として保存した。自然言語の意味、本人の自由な意思、対応の真正性、全目録の完全性は検査していない。

## 7. 保留は現在の利用許可ではない

未解決であるため特定の状態変更を行わないことと、現在の活動を旧許可で継続することは別である。

前者は記録を根拠なく改変しないための規則であり、後者は現在の行為についての判断である。この二つを結べば、未解決の通知がかえって既存状態の保護装置になる。今回の出力は現在の実施許可を推定せず、この判断を未解決として残した。

## 結論

> 文章を一字も変えなくても、結ぶ線を間違えれば、別の歴史を作れる。

記憶を保存するには、内容に加え、その内容をどの出来事へ作用させたかを保存する必要がある。候補を候補のまま残すことは、復元の放棄ではなく、復元が現在へ与える権限を限定することである。

次の未実施の入口は「保留中の現在」。照合を保留するあいだ、何が現在の行為を支えるのかを考える。
