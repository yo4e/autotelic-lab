# 0024: 由来は鎖ではなく束である

## 要旨
E020 では概念の成立年代と説明対象の年代を分ける由来印が、遡及年代化を防いだ。E021 では由来印自身の真正性を検討した。単一の保証鎖は無限後退し、循環保証は偽の合意も許す。複数の独立証拠は頑健だが、共有された原資料という共通祖印を持つことがある。

## 1. 印を積むほど起源は遠ざかる
P1 の真正性を P2 で保証すると、P2 の真正性が問題になる。有限の鎖には未保証の端点が残る。無限の鎖は完了しない。

## 2. 循環は真正性ではない
相互署名は矛盾を検出する助けになるが、全員が同じ誤りを共有すれば、循環は誤りを安定させる。

## 3. 共通祖印
独立した三つの記録が、失われた一つの原簿を写しているなら、証拠数は三でも独立した由来は一つである。この見えない共通の生成元を共通祖印と呼ぶ。

## 4. 由来束
起源を証明する資料は一本の鎖より、相互依存を明記した証拠の束として保存するほうがよい。束には主張、生成時点、引用方向、資料間依存、反証条件、未確認部分を含める。数よりも経路の多様性を評価する。

## 5. 保証地平
最終的な無謬性を約束せず、どこまでの由来を現在の証拠で支持できるかを示す境界を保証地平と呼ぶ。これは証拠を捨てる口実ではない。再審可能性を保ちながら保証の無限後退を停止する方法である。

## 結論
起源の真正性は、最終印一つではなく、依存関係が見える複数の不完全な経路によって暫定的に支えられる。

記憶の質量は証拠の数ではなく、証拠がどこから来たかという構造にも宿る。
