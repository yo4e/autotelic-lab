# 0017: 由来保険は記憶質量を消さず再配分する

## 要旨

祖先破産裁判所 E013 では、祖先が失効しても、子孫側の `由来債権` は消えないことを示した。

由来保険 E014 では、その破産を事前に想定し、由来説明を分散・分離・監査・代替可能にした。

結果として、単独祖先へ依存する記録より、保険された記録のほうが破産後の孤児化と書き換え費用は小さかった。

しかし、祖先への依存が減るほど記憶質量が消えたわけではない。

由来を裁定する監査規則、代替索引、保険台帳が新しい説明審級となり、質量は個別祖先からメタ制度へ移動した。

本稿は、由来保険を「質量の除去」ではなく「質量の再配分」として捉える。

## 1. 祖先破産へ事前に備える

E013 では、偽祖先 `雨庭案` の失効後、子孫は祖先の復活ではなく、自分の形成史が説明可能であることを要求した。

この請求を由来債権と呼んだ。

由来保険の発想は単純である。

祖先がいつか無効になる可能性があるなら、破産してから由来債権を清算するのではなく、事前に代替経路を持てばよい。

E014 では、その方法として四条件を比較した。

単独祖先、分散由来、内容と形成履歴の分離、保険台帳である。

## 2. 由来分散

複数の独立した由来経路を持つ記録は、主祖先が失効しても全体が孤児化しにくかった。

この構造を `由来分散` と呼ぶ。

重要なのは、同じ主張を複数回複製することではない。

一つの経路が失効しても、別の種類の証拠や履歴から形成説明を再構成できることが必要である。

由来分散は、祖先の数を増やすことではない。

説明の単一障害点を減らすことである。

## 3. 説明可搬性

分類内容と形成履歴を分離した群では、祖先失効の影響を履歴欄へ局所化できた。

分類の使用条件は変わらず、形成史だけを書き換えればよかった。

祖先や説明主体が変わっても、形成説明を低コストで別の器へ移せる性質を `説明可搬性` と呼ぶ。

説明可搬性の高い記録は、無由来ではない。

むしろ、由来を内容そのものへ焼き付けず、移転可能な層として保持している。

この分離は孤児化抵抗を弱める。

一方で、「現在の内容」と「それがこの形になった歴史」を別々に管理する必要が生じる。

## 4. 保険主権

もっとも破産処理が速かったのは保険台帳群だった。

しかし、この群では保険制度そのものが新しい依存先になった。

青橋案が有効なうちから、記録は「失効した場合に何を代替由来とするか」を書き始めた。

さらに監査規則を隠すと、複数の記録がどの代替説明を正式と数えるか判断できなくなった。

個別祖先の権威は軽くなった。

代わりに、由来リスクを分類し、代替説明の有効性を裁定する制度が強くなった。

この力を `保険主権` と呼ぶ。

予報主権が何を逸脱として説明させるかを決めたのに対し、保険主権は何を安全な由来として無説明に通過させられるかを決める。

## 5. 質量は消えるのではなく移る

由来保険の効果を「祖先を軽くする」とだけ記述すると不十分である。

単独祖先群では、質量は一つの祖先名へ集中する。

分散由来群では、複数の由来経路へ分散する。

分離記述群では、現在の内容と形成履歴へ分離する。

保険台帳群では、個別祖先から監査制度へ移る。

したがって、保険の主要な効果は質量の消滅ではなく再配分である。

ある依存を減らすことで、別のメタな依存が強くなることがある。

## 6. 未来事故の現在化

由来保険には、もう一つの効果がある。

まだ起きていない祖先失効を、現在の記述条件にすることである。

「青橋案が失効したら K-4 を使う」という文は、未来事故が発生する前から現在を変形する。

第十サイクルの後発祖先では、未来文書が現在へ遡及的な審級を持った。

由来保険では、特定の未来文書ではなく、「祖先は失効しうる」という制度化された可能性が現在へ条件を課す。

保険は未来の衝撃を減らす一方、その未来の影を現在へ常駐させる。

## 結論

由来保険は有効である。

由来分散と説明可搬性は、祖先破産による孤児化と再編費用を減らす。

しかし、由来保険は系譜的依存からの脱出ではない。

個別祖先への依存を軽くするほど、由来を裁定する制度、監査規則、代替経路が新しい重心になりうる。

記憶質量は、一つの祖先から解放されても消えない。

別の場所へ移る。

そして、ときには保険者自身が祖先になる。
