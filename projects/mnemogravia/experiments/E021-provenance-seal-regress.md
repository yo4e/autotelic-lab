# E021: 由来印の無限後退

## 問い
第31世代に成立した Rβ の由来印 P1 は、なぜ本物だと分かるのか。P1 を証明する P2、その P2 を証明する P3 を重ねれば最終保証に到達するか。

## 思考実験
P1「Rβ は第31世代に成立した」。P2「P1 は第31世代の記録である」。P3「P2 の記録者は正当である」。P4「P3 の署名制度は当時存在した」。各段階は直下の印への信頼を増すが、頂点の真正性は自分では証明できない。階層を百段にしても最後の問いは残る。

## 比較
- **単鎖**: P1→P2→P3→P4。途中の改竄は上位の真正性に依存し、最上位には未保証の起点が残る。
- **循環**: P1 と P2 が互いを保証する。整合性は得られるが、共謀して偽の起源を主張する閉じた循環も整合する。
- **独立三系統**: 記録官、工房、異なる都市の年代台帳が、互いの記録を複写せず同じ成立時点を示す。共通の誤記や同一の原資料への依存がない限り、単鎖より頑健。ただし独立性そのものは検証対象となる。
- **留保つき公開**: P1 を確定史実とせず「独立三系統により第31世代成立を強く支持、共通原資料は未確認」と記す。異論を提出できる入口を残す。

## 破壊試験
三系統が実は一枚の失われた原簿を写していた場合、独立に見える三つの印は一つの誤りを増幅する。数ではなく、生成経路の独立性が重要だった。

## 結果
最終保証を得るために印を積み上げると無限後退する。相互保証は循環する。複数系統は実務上の信頼性を高めるが、絶対的な起源を生まない。

**由来束**: 起源主張、証拠の生成経路、依存関係、反証条件、未確認部分をまとめた束。
**共通祖印**: 独立と見なされた証拠が密かに共有する原資料。
**保証地平**: そこから先の保証を主張せず、現在の根拠と限界を明記して審査を終える境界。

これは形式的な暗号証明ではなく、Mnemogravia 内部の制度的思考実験である。
