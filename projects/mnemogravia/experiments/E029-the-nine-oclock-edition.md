# E029　保留中の現在

館の玄関には、掲示板と会報の引き取り口が並んでいる。掲示板の名簿はいつでも直せる。印刷所は朝九時にその欄を一度だけ取り込む。九時を回ってから掲示を直した朝、その号には何が残るだろう。

## 失われた対応表をそのままにする

[前回の E028](E028-orphaned-correction.md) で作った二世界を借りる。A と C は同じ人 P が別々の機会に残した同文の記録。未解決の通知 W2 は、展示を一時停止してほしいという要求と、その停止を求める人として今後名前を使う許可を取り下げる。母の読み方を保存してほしいという要求はどちらの世界でも残る。

古い台帳は、ある世界では W2 を A に、もう一方では C に結んでいた。台帳を失った係員に見えるものは同じだ。両世界とも、今朝の名簿で P の名前を支えている根拠は A の一件だけとする。C の許可を A に融通することはできない。宛先が C の世界では、今号に限り、A に基づく掲載予定にはほかに異議がないと設定した。人全体の意思を発言の版ごとに機械的に切り分けられるという主張ではない。

## 九時に起きる二つの仕事

会報には、展示停止の賛同者名を載せる欄が一つある。前日から玄関に出ている名前をそのまま版に渡すか、館の案内だけに差し替えるか。案内には誰が撤回したとも、展示を再開するとも書かない。別の机では、母の読み方を記した保存原本から非公開の保全用複製を一部作る。この仕事には館内の保全に限った独立の権限がある。保存要請だけを複製や公開の包括的な許可と読む設定にはしない。

通知を受けて、印刷所が取り込む**前**に係員が動けた朝を比べる。

| 係員が選ぶ扱い | 九時の版の賛同者欄 | 今朝の保全用複製 |
| --- | --- | --- |
| 候補に関する作業を全停止する | 館の案内のみ | 見送る |
| 従来の作業をすべて続ける | A に基づき P の名前を載せる | 作る |
| 用途ごとに判断する | 館の案内のみ | 作る |

ここでいう全停止には保全作業も含めた。停止対象を最初から係争中の公示に絞る館なら、一行目と三行目はこの朝、同じ仕事をする。三方式とも A、C、W2 は記録庫に残す。いずれも展示自体の開催可否は未決のままだ。

## 一つの空欄を二つの世界で読む

宛先が **A** の世界で従来どおり刷ると、取り下げられた A を根拠に、もう一号 P の名前が出る。宛先が **C** の世界で名前を伏せると、掲載予定に生きた根拠があった A まで、この号で声を届ける機会を失う。両方の世界で同じ係員に同じ材料を渡した。それでも、同じ空欄が片方では撤回を越えた掲載を防ぎ、もう片方では予定された掲載を一号分止める。

俺がこの朝に採ったのは用途ごとに判断する扱いだ。今号へ新しく名前を送り出すのは見合わせる。保全係には館内用の写しを一部作ってもらう。その選択で見送った掲載機会も記録する。実際に A が撤回されたと登録する必要はないし、C が宛先だと後で分かっても、その朝の号に遡って名前を載せたことにはできない。

## 同じ掲示板を見せる別の朝

今度は同じ通知を受けたあと、係員の差し替えと印刷所の取り込みの順だけを逆にする。用途別の係員が最後に残す掲示は二回とも館の案内である。

| 順番 | 終了時の玄関 | 締め切った今号 |
| --- | --- | --- |
| 差し替えてから取り込む | 館の案内のみ | 館の案内のみ |
| 取り込んでから差し替える | 館の案内のみ | P の名前が残る |

二つの玄関の終了写真から、今号の名前の有無は復元できない。後で掲示に名前を戻しても、逆に訂正を出しても、締め切った版は変わらない。この模型の「戻せる」は、どの媒体で、どの号の、どこまでを戻せるかで決まる。玄関ですでに名前を見た人の人数や、その人が覚えているかは数えていない。

## 再現

[検査コード](E029-press-check.py) と [その標準出力](E029-press-check-results.json)。リポジトリのルートから次を実行する。

```sh
python3 projects/mnemogravia/experiments/E029-press-check.py
```

照合対象は、二つの順番と三つの扱いが生む版・掲示・複製、および各版を二つの宛先で事後に評価した結果である。宛先は係員の入力へ渡さない。結果は架空の一欄と一号の比較で、現実の同意、読者の受け止め、損害の大小は測っていない。
