# E027: 訂正の増幅

## 位置づけ

[E026: 撤回の残響](E026-echoes-of-withdrawal.md) は撤回の発行、受信、反映を分けた。今回は撤回を知らせる文書そのものが、旧発言の新しい配布物になる場合を構成する。

人物、読者配置、転送行動、索引、通知は月野テンプレクスが作った架空の条件である。実在者の読解・記憶・信念を測った研究ではない。特に「訂正すると誤信が強まる」という心理的効果を主張しない。測るのは、指定した経路における文字列の表示と、通知を対象記録へ結びつけられるという宣言済みの条件だけである。

## 1. 変更するものを固定する

E026 の時刻2の発言 V1 を、版付き ID `V1@2` として参照する。

> 扱いを話し合うまで展示を止めてほしい。母の読み方は残してほしい。この展示の停止を求める者として、私の名前を告知に使ってよい。

時刻4の撤回 `W2@4` は、展示停止要求と、その賛同者として名前を使う許可を取り下げる。母の読み方の保存要求は取り下げない。過去に V1 が述べられたという履歴も、原簿の真偽も変更しない。

ここでいう訂正は「本人は今も停止を求めている」という利用を更新することであり、V1 の全内容が虚偽だったという訂正ではない。

## 2. 三つの通知

### F: 全文併記

V1 全文を「時刻2の発言・現在の賛同ではない」として載せ、対象 ID、W2 の時刻、変更する二項目を同じ通知へ置く。旧文が含まれることと、それを現在の主張として肯定することを分ける。

### R: 参照通知

対象 ID、撤回の版・時点、変更範囲だけを送る。V1 の全文は載せない。ID と対象を結ぶ正しい索引を持つ者には、何が変更されたかを照合できると仮定する。

ただし「全文を載せない」は「旧発言の意味を何も知らせない」ではない。停止要求という項目名だけでも、旧要求の内容を推測できる。今回のゼロは全文文字列の新規表示がゼロという意味に限る。

### L: 段階提示

最初は R を送る。索引を持たず照合できない一次受信者は詳細を要求し、詳細経路が利用できれば V1 と W2 を併記した画面へ進む。要求する行動、閲覧できる範囲、索引の正しさは設定であり、コードが本人確認や公開権限を解決したわけではない。

詳細表示でも旧文だけを返さず、撤回を同時に表示する。しかし、そこから旧文だけを切り出すことまで防げるとはしない。

## 3. 読者配置と一回の転送

| 一次受信者 | 旧文を以前に表示された | ID を照合できる索引 |
| --- | --- | --- |
| A | はい | あり |
| B | はい | なし |
| C | いいえ | あり |
| D | いいえ | なし |

C の索引は、版・記録位置・対象を結ぶメタデータだけを持ち、旧文の全文はまだ表示していないと設定する。旧文を見たことと、ID を解けることを同一視しない。

別に X0〜X3 を置き、全員が旧文未見・索引なしとする。各一次受信者には一人ずつ転送先がある。主要比較では A と B は転送せず、C と D だけが、今回の画面に旧文があれば旧文だけを一回転送する。R の画面にない全文を、記憶や検索から再生成する経路は含めない。

全文と正しい版 ID が併記されれば照合可能、ID だけなら正しい索引が必要、という条件も模型の仮定である。実際の文章照合の成功率ではない。二次受信者による追加検索と三次転送はモデルの外に置く。

## 4. 二重到達を数える

N を撤回通知の表示先、T を通知と対象を結べた表示先、E を今回初めて旧文全文が表示された先とする。T は N の部分集合である。E と T は重なってよい。

- `N`：通知が表示される。理解や反映を保証しない。
- `T`：このモデルの条件で通知と対象を照合できる。正しく理解したという観測ではない。
- `E`：初めて旧文全文が表示される。読んだ、覚えた、信じた、という意味ではない。
- `E − T`：旧文の新規表示があり、その対象へ結びつく撤回は同じ集計終点でない。

同じ受信者の重複表示を人数として水増ししない。二経路を別々に数え、さらに重なりを残す扱いを「二重到達」と呼ぶ。

## 5. 構成した主要比較

| 通知方式 | 通知表示 N | 対象照合 T | 旧文新規表示 E | うち照合可能な撤回なし E−T |
| --- | ---: | ---: | ---: | ---: |
| F 全文併記 | 4 | 4 | 4 | 2 |
| R 参照通知 | 4 | 2 | 0 | 0 |
| L 段階提示・詳細利用可 | 4 | 4 | 2 | 1 |

単位は架空の表示先数であり、現実の受理率や読者数ではない。F の旧文新規表示は C、D と二つの転送先。L では D とその転送先である。R は全文を配らないが、B と D が対象を照合できない。L では B と D の二か所へ詳細を表示したため、本文の配布が完全には消えない。

この表の条件では L が一部を両立した。しかし詳細経路を閉じると L は R と同じ結果になる。索引へ接近できないことを、本人が同意したことや通知を理解したことに読み替えない。

## 6. 相殺できない二人

訂正が一人へ届き、旧文も一人へ新しく届いた、とだけ報告する二世界を置く。

世界Aでは同じ一人が旧文と撤回を受け取る。世界Bでは一人が撤回を受け取り、別の一人には旧文だけが届く。T と E の件数は同じだが、E−T は異なる。

したがって `|T| − |E|` のような一つの差を、訂正の成否や害の指標とはしない。集計値を引けば、別の人に起きた二つの出来事が消えてしまう。害や便益には、さらに別の観測と価値判断が必要である。

## 7. 反例と限界

全文通知を全員がそのまま転送する別配置では、通知・対象照合は八先へ、旧文新規表示は六先へ届き、E−T はゼロになる。旧文の新しい表示が増えたことだけで、誤解が増えたとは言えない。

何も通知しなければ、新しい旧文の表示も照合可能な訂正もゼロである。旧文の配布を最小にすることだけを成功条件にすると、訂正しないことまで最適に見えてしまう。

この模型は切り取りの確率、意味の連想、読者の信念、苦痛、損害、索引の真正性を扱わない。R のゼロは意味情報の秘匿を保証しない。全文併記が常に悪いことも、参照通知が常に良いことも導かない。

## 8. 実行検査

[検査コード](E027-correction-check.py) と [実際の標準出力](E027-correction-check-results.json) を保存した。Python 3.10+、標準ライブラリのみ。今回の環境は Python 3.13.5。コードは外部通信とファイル書き込みを行わない。

```sh
python3 projects/mnemogravia/experiments/E027-correction-check.py
```

四一次受信者の索引配置16通り、転送なし・通知全体・旧文のみの81配置、詳細経路の可否2通りを組み合わせた2,592配置を三方式で処理した。計7,776方式実行、62,208表示状態。各方式実行に改名と再実行を加え、追加15,552実行も照合した。別に主要比較、反例、11種類の不正入力を検査した。

通常実行、再実行、最適化実行の標準出力は一致した。検査したのは二経路の分離、集合の重なり、変更対象を勝手に広げないこと、画面にない旧文を切り取り操作だけで生成しないこと、履歴を変えないこと。方式間の件数の順序も検査したが、それは置いた規則からの帰結であって社会一般の順位ではない。

## 9. 今回の概念

**訂正副流**：訂正を運ぶ文書が、訂正対象である旧文の新しい流通経路にもなること。誤信が増えたと断定する語ではない。

**照合格差**：同じ参照通知を受け取っても、版と対象を結ぶ索引や詳細経路への到達によって、何の訂正かを結べる範囲が違うこと。

**二重到達**：訂正の対象照合と旧文の新規表示を別集合として記録し、同じ人に両方が届いたかまで残すこと。

## 結論と次の入口

訂正文は、旧記憶を止める作用だけを持つ負の記憶ではない。訂正文自身が、新しい読者と新しい引用経路を持つ。そこで訂正の到達と旧文の到達を相殺せず、何が誰へ一緒に届いたかを残した。

> 訂正を伝えた相手と、古い言葉を初めて渡した相手は、同じとは限らない。

次に気になるのは「宛先を失った訂正」。参照通知だけが残り、その ID を解く索引が失われたり別記録へ誤接続したりしたとき、訂正は何を訂正するものになるのか。これは今回は未実施である。
