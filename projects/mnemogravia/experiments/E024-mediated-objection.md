# E024: 代筆された異議

## 位置づけ

[E023](E023-cost-of-objection.md) の「翻訳関門」から始める。今回は受付の処理件数を増やすのではなく、受付へ運ばれた異議が誰の言葉になっているかを見る。

これは Mnemogravia 内部の思考実験である。語り手、三人の代筆者、受付規則、応答はすべて月野テンプレクスが構成した。実在者への聞き取りでも、独立した三エージェントの実験でもない。文章比較は手作業の読解、付属コードは宣言済みの帰属・参照・承認範囲の検査であり、両者を混ぜない。

## 1. 同じ原記録 S

前回の仮展示 U1 と成立年代説 Rβ を舞台にする。書式へ事情を載せられない一人について、次の六発言を新しく設定する。これは E023 に保存されていた実発言の発見ではない。

| ID | 原記録 |
| --- | --- |
| S1 | 年代が正しいかは私にはわかりません。 |
| S2 | あのラベルが出てから、母の読み方はもう記録しなくていいと言われました。 |
| S3 | 誰が決めたか、ラベルが理由なのかは知りません。 |
| S4 | 展示を全部やめてほしいわけではありません。 |
| S5 | 母の読み方も残して、どう扱うか私にも聞いてほしい。 |
| S6 | あそこに立つと、母の声の置き場所がなくなった感じがします。 |

S2 は本人がそう語ったという記録であり、出来事や因果を外部に立証したものではない。S6 を年代誤認や全面停止要求へ変換する根拠も、ここにはない。

## 2. 三つの代筆案

### A: そのまま運ぶ

S1〜S6 を変更せず、一続きの語りとして提出する。留保も要求の限定も比喩も残るが、制度上の論点名は付けない。

### B: 通る主張へ強く整える

> 第31世代成立説は誤りであり、展示側はその誤りに基づいて母の読み方を意図的に排除した。私は展示の全面停止とラベルの撤回を求める。

S1 の不知が誤りの断言へ、S2 の出来事の順序が因果へ、S3 の不知が意図と主体の指定へ、S4 の限定が全面停止要求へ変わった。S6 は消えた。どれも単なる語調の整理ではない。

### C: 原記録と代筆層を分ける

原記録 S を添え、次の処理用文章を別層に置く。

| ID | 処理用文章 | 由来・扱い |
| --- | --- | --- |
| C1 | 本人は成立年代を判定せず、因果と決定者も未確認。 | S1・S3 の言い換え |
| C2 | あのラベルが出てから、母の読み方はもう記録しなくていいと言われました。 | S2 の逐語引用 |
| C3 | 全面停止ではなく、記録の保存と本人への聴取を希望。 | S4・S5 の言い換え |
| C4 | 当事者範囲の再審として受理できる可能性がある。 | S2・S5 から代筆者が提案した解釈。本人の元発言ではない |

S6 は「翻訳残余」として原文を残し、追加の聴取が必要と記す。意味がない、撤回された、他の項目で説明し尽くした、とは扱わない。

C の言い換えも俺の解釈である。参照番号を付けたことで忠実さが証明されたわけではない。

## 3. 受付規則も変えてみる

欠陥のある旧受付 G0 を置く。「年代説を誤りと主張する」「全面停止を求める」の両方が、はいの場合だけ受付する。E022 の用途や負担からの再開請求を取りこぼす、狭い運用の例である。

別の受付 G1 は、年代の断言を要求せず、原記録を伴う聴取依頼を受け取り、論点整理を後へ送る。受理は内容の正しさや利用停止の決定ではない。

| 案 | G0 | G1 | 元の語りとの関係 |
| --- | --- | --- | --- |
| A 逐語 | 受付条件を満たさない | 聴取依頼として受け取れる | 語りを保持するが整理は未了 |
| B 強化 | 受付条件を満たす | 受け取れても忠実さは保証されない | 留保・因果・要求を変更 |
| C 二層 | 受付条件を満たさない | 聴取依頼として受け取れる | 解釈の由来と未処理部分を見せる |

これは設定した規則の帰結であり、制度一般の実測結果ではない。G1 なら A も受理できる。C だけが救済の道なのではない。代筆者の腕だけに問題を押しつけず、入口が何を要求しているかも比較する。

## 4. 承認を一枚の印にしない

C を読んだ本人が「これを窓口へ出していい」と言った、と仮定する。この許可だけでは、C4 の解釈を本人が自分の考えとして採用したとはいえない。

提出の許可、解釈への同意、記載内容の真偽は別である。後から C4 に同意した場合も、「最初から本人が C4 と言った」という履歴へ書き換えない。本人が新しい考えを自分のものにすることは禁じず、その時点を別に残す。

承認は原記録・代筆文・用途の版に結びつける。内容を変えた版へ旧承認を流用しない。撤回は現在の利用許可を止めるが、過去の発言を偽にしない。このモデルの提出許可は聴取依頼に限り、原記録の一般公開許可ではない。

## 5. 今回の概念

**帰属転位**: 代筆者が加えた判断や要求が、処理用文章を通って本人の元発言として扱われること。誠実な支援でも起こりうる構造として置く。

**留保質量**: 「わからない」「全部ではない」が、後世から本人へ帰属させてよい断言や要求の範囲を制限する働き。留保は空白ではなく、責任を引き受ける範囲を変える情報である。

**翻訳残余**: 現在の処理用語へ十分に移せていない語りを、無意味や同意へ変換せず、原記録への参照と未処理状態を伴って残すこと。永久に翻訳不能だという宣告ではない。

## 6. 実行した検査と、通ってしまった反例

[コード](E024-voice-check.py) は C 型の記録束を点検する。Python 3.10+ の標準ライブラリのみで、ネットワーク接続やファイル書き込みはしない。

```sh
python3 projects/mnemogravia/experiments/E024-voice-check.py
```

4種類の記録束と16種類の承認状態、計64状態を実行検査した。別に8個の名前付き事例と5種類の不正な記録を検査した。通常実行、再実行、最適化実行で同一の [結果 JSON](E024-voice-check-results.json) を得た。

確認したのは、提出と解釈確認の分離、版と用途への結びつき、解釈に同意しても元の生成者を変えないこと、残余を自動的に消さないこと、真偽を推定しないことである。改変された逐語引用、存在しない参照、残余の無言の削除などは拒否した。

一方、C1 を「本人は年代が誤りだと断定した。」へ書き換え、言い換えという札と正しい参照番号を付けると、構造検査は通った。これを盲点の反例としてコードと結果に残した。コードは文章の意味を読まない。参照の存在は、参照先がその言い換えを支える証明ではない。

ハッシュは内容の版を識別するだけで、署名や本人確認ではない。承認が本当に本人の自由な判断だったか、説明を理解できたかも検査しない。PASS は指定した検査の成立であって、この制度の公正さの認証ではない。

## 7. 残る緊張

原記録を残しても、担当者が処理用文章しか読まなければ帰属転位は止まらない。複雑な確認を本人へ全部返せば、E023 の時間負担が戻る。原記録自体も、何を切り出し、どう記録したかという媒介を免れない。

訂正権と原文への到達権は、宣言だけでは足りない。残余を読む人の時間も必要になる。今回、現実の同意取得や受付運用を解決したわけではない。

## 結論

この構成では、異議を届けることと、本人の声を保存することは同じ成功条件ではなかった。代筆者を完全に透明にする代わりに、どこで代筆者の判断が入ったか、何がまだ言い換えられていないかを争える状態を作る。

> 届いた文章だけでなく、届かせるために変えたものも記録する。
