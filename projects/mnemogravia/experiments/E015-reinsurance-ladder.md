# E015: 再保険階梯

## 目的

由来保険 E014 では、個別祖先の失効へ備える保険台帳そのものが、新しい説明審級になった。

今回は、その保険台帳の失効へさらに上位の保険を置き、二層、三層と重ねたとき、説明可能性が本当に安定するかを見る。

また、どの層も自分では保証できない共通前提があるか、連鎖を止める方法があるかを調べる。

## 装置

第一保険者 `I1` は、主祖先が失効した場合に独立観測と旧版差分から代替由来を作る。

第二保険者 `I2` は、I1 が失効した場合に I1 の監査履歴から選定基準を再構成する。

第三保険者 `I3` は、I2 が失効した場合に同じ処理を行う。

三層は共通して、次を前提にする。

- 同じ頁を同じ頁として追跡できる
- 改訂の前後関係が判定できる
- 監査票と対象頁の対応が保存される

四群を作る。

1. 一層群 L1：I1 のみ。六頁目で I1 を失効。
2. 二層群 L2：I1 を I2 が支える。六頁目で I1、九頁目で I2 を失効。
3. 三層群 L3：I1、I2、I3。六、九、十二頁目に順次失効。
4. 猶予群 F：I1 と I2。両方が失効し代替経路も決められない場合、由来を `未決` と記し、証拠と矛盾を保存したまま先へ進む。

十三頁目には、全層が共有する「頁同一性と改訂順序を保証する索引」も一時的に無効化する。

## 結果

### L1

I1 の失効後、どの代替由来を正式とするか決められなくなった。

### L2

I1 の失効は I2 が処理した。

しかし I2 も失効すると、同じ問題が一段上で再発した。

> I1 の選定理由は I2 が説明した。では、I2 を選定理由としてよい理由は誰が説明するのか。

### L3

I1 と I2 の失効には耐えたが、現在の頁に上位層への条件文が増えた。

> I1 を採用する。ただし I1 が失効した場合は I2、I2 が失効した場合は I3 を優先する。

保険を重ねるほど、まだ失効していない上位層が現在の書式へ入り込んだ。

I3 まで失効すると複数頁が未決になった。

さらに共通索引を無効化すると、三層すべての履歴対応が同時に読めなくなった。

> 三つの保険者は別々ではなかった。同じ頁が同じ頁であり続けることを、三者とも無保険で借りていた。

再保険の全層が共有し、同じ構造の内部からは保証できない前提を `無保険核` と呼ぶ。

### F

I1 と I2 が失効したあと、二頁を `由来未決` とした。

本文、旧監査票、矛盾する代替説明、失効履歴は保存した。

後継は新しい仮祖先や第三保険者を作らなかった。

> 説明がないことと、説明がなかったことにすることは違う。

説明要求を消さず、証拠を保持したまま決着を先へ送る状態を `由来猶予` と呼ぶ。

## 判定

再保険は局所的には有効だが、失効点を上位へ送るだけでは連鎖を終わらせない。

また、層を増やしても、頁同一性や改訂順序のような共有前提が一度に崩れれば全層が同時に弱くなる。

無限後退を止めたのは最終保険者ではなかった。

「説明できない状態を、偽の説明で閉じずに未決のまま保存してよい」という手続きだった。

由来猶予は説明要求を放棄しない。

ただ、今すぐ決着しなければならないという圧力だけを止める。
