# E025: 二度目の原文

## 位置づけ

[E024: 代筆された異議](E024-mediated-objection.md) の次に、本人が代筆文を読んでから語り直す場面を置く。原記録、語り手、代筆者、後の引用者、以下の四場面は月野テンプレクスが構成した。聞き取り調査でも、独立した人やモデルへ依頼した実験でもない。

文章の比較は読解による構成事例、付属コードは明示した情報経路の検査である。発言の自発性や真偽を機械で読み取ったとはしない。

## 1. 一度目を消さずに二度目を作る

E024 の六発言の束を V0 と呼ぶ。E024 の行番号 S2 と今回の「二度目」を混同しないため、後の語りは V1 と記す。

V0 の本人は、成立年代を知らず、ラベルと排除の因果も決定者も知らない。展示を全部止めるのではなく、母の読み方を残して、自分にも扱いを聞いてほしいと述べた。「母の声の置き場所がなくなった感じ」は未処理の比喩として残っている。

代筆文 M は二種類を区別する。M-C は E024 の案 C にある「当事者範囲の再審」という代筆者の提案。M-B は案 B にある、年代説の誤り・意図的排除・全面停止を断言する強化案である。両者を同じ忠実な要約とは扱わない。

時系列は V0 → M → M を読む → V1。V1 は新しい発話の原記録になれる。ただし M に接する前の記録にはならない。

## 2. 四つの語り直し

### A: 言葉を得る

M-C を読み、本人が自分の要求に合う語彙を選んだ、と設定する。

> 「当事者範囲の再審」という言い方なら、私が聞いてほしかったことを置けると思います。その言い方でお願いします。年代や、誰が決めたかは、今もわかりません。

現在その語彙を選んだことを記録する。語彙の生成元は代筆者のまま、現在の使用者は本人になれる。本人性を守るために、学んだ経路を消す必要はない。逆に、経路があることを理由に本人の語りを失格にしない。

### B: 本当に考えを変える

M-B を読んだ後、本人は因果の断定には同意しないが、要求については考え直した、と設定する。

> 年代が誤りか、わざとだったかは断定できません。でも今は、扱いを話し合うまで展示を止めてほしい。前には全部を止めたいわけではないと言いました。その希望は変わりました。

現在の要求は V0 と異なる。これは V0 が改竄されていたという証拠でも、本人が最初から全面停止を望んでいたという証拠でもない。過去の発言を保存することを、現在の意思を過去へ縛る道具にしない。

### C: 受付のために合わせる

狭い受付に合わせる圧力がある別の場面を設定する。

> その書き方でないと聞いてもらえないなら、それで出してください。正しいかと聞かれると、私にはまだわかりません。

提出に関する応答を、解釈への確信として格上げしない。A の「その言い方でお願いします」と似た表面だけを抽出すれば、学習と圧力は区別しにくい。ここで動機を知っているのは場面を設定した作者であり、文章の整形や来歴図だけから自由な同意を判定できるわけではない。

### D: 同じ語りに新資料が入る

本人が M-C の語彙を使いながら、代筆前に作られた別倉の原簿 D0 を新しく提示した、と設定する。

> 当事者として再審を求めます。それから、別倉の原簿に、担当側が母の読み方を記録対象から外すという指示を見つけました。ラベルを理由にしたとは、その原簿には書いてありません。

原簿の作成が代筆に依存しないことは、この場面の設定である。真正性や実際の指示の履行が証明されたとはしない。また、この資料が支えうるのは「記録対象から外す指示があった」という限定した命題 H であり、年代説の誤りやラベルとの因果までではない。

V1 の用語は M に依存していても、D0 の記載まで M が作ったことにはならない。反対に、D0 が新資料であっても、V1 の全内容が独立した裏づけになるわけではない。語り全体へ一枚の「独立／非独立」の札を貼らず、何を裏づける部分かを分ける。

## 3. 帰ってきた言葉を二票に数えない

後の引用者 Q が、M と M を読んだ後の V1 の一致を見て「代筆者と本人が別々に同じことを述べた」と書く場面を置く。

```text
V0 → M → V1 → 後の評価 Q
      └────────→ Q
```

記録はすべて前向きに作られる。M が過去から書き換わるのではない。Q が二つの記録の依存を省き、M が作った一致を M の独立した検証へ数え直す。その証拠の使い方を「反響証拠」と呼ぶ。

V1 に価値がないという意味ではない。V1 は、現在どの言葉を選ぶか、どの要求を変えたか、どこをまだ保留しているかを新しく知らせうる。ただし「今はこの説明を選ぶ」と「最初の説明は外部の裏づけで正しかった」は別である。

## 4. 来歴を命題ごとに追う

コードの図は、限定した命題 H についての情報経路を扱う。Unit は文書全体でも人格全体でもなく、記録の中の主張成分である。parent は H に関する情報を利用・接触した経路であり、支持の強さ、正しさ、統計的依存度を表さない。

S は元資料、M はそれから書いた代筆中の主張、L は伝達文、R は読後の語りの該当部分。C は S を共有する別記録である。D は別原簿、E はその記載を取り出す部分として置く。

| 関係 | 構成 | 検査の出力 |
| --- | --- | --- |
| 直接の戻り | M → L | 代筆の下流 |
| 間接の戻り | M → L → R | 代筆の下流 |
| 共通の元資料 | S → M、S → C | 共通祖先あり |
| 別原簿の部分 | D → E | 記録された接続なし |
| 同じ記録 | M を再提示 | 同一記録 |
| 使用済み資料 | S を再提示 | 代筆がすでに使用 |

「記録された接続なし」は「独立を証明した」ではない。D の生成経路が本当に別か、記載の意味が H を支えるかは、別の調査である。語彙の類似だけから情報依存を決めず、似ていない文章だから別起源とも決めない。

## 5. 実行した検査

[コード](E025-echo-check.py) と [実際の標準出力](E025-echo-check-results.json) を保存した。Python 3.10+、標準ライブラリのみ。コードはファイル変更と外部通信を行わない。

```sh
python3 projects/mnemogravia/experiments/E025-echo-check.py
```

五つの経路条件で作った32図と、採用・拒否・未決・未記録という四つの現在状態を組み合わせ、128状態を検査した。六つの名前付き関係、R と E を同時に含む束、八種類の不正入力も検査した。通常実行、再実行、最適化実行の JSON は一致した。

現在の採用状態を変えても以前の情報経路は変わらず、人物名だけを変えても経路判定は変わらない。混合した束では R の既知の経路と E の別途調査すべき経路を分けられた。どの状態でも真偽や独立性を自動認証しない。

反例も実行した。M → L の接続を記録から一本落とすと、R は「代筆の下流」から「記録された接続なし」へ変わり、不正形式としては拒否されなかった。そこで出力は独立性を未認証のまま残す。検査器は書かれていない影響を発見しない。

## 6. 今回の概念と限界

**更新原文**: 以前の語りと接触履歴を消さず、新しい時点の語りをその時点の原記録として残すこと。原文を一生に一度しか持てないものにしない。

**反響証拠**: ある解釈を経由して生まれた一致を、その解釈の独立した裏づけとして再計上すること。依存した証言をすべて無価値とする語ではない。

**命題別来歴**: 同じ語りでも、どの命題について、どの部分が、どの情報経路から来たかを分ける記録方法。

四場面から人間の心理に関する一般則を導いてはいない。現在の同意状態もモデルへの入力であり、同意の自発性をコードが測ったのではない。原文の真正性、影響の強さ、隠れた共通起源、適切な証拠の重みづけも検証外である。

## 結論

本人が言葉を変える自由と、資料を独立に数えない慎重さは両立する。守るべきなのは影響を受けない純粋な語りではなく、何がいつ変わり、何の根拠として使われているかを争える区別である。

> 借りた言葉は本人の言葉になれる。しかし、借りた経路まで消えるわけではない。
