# E009: 未来墓地

## 目的

実現しなかった未来を、名前、失敗日、失敗理由、影響した頁とともに保存したとき、敗北祖先の系譜解像度がどう変わるかを観測する。

とくに、かつて「こうなれ」と現在へ要求した未来が、墓碑化されたあとに「こうなるな」という逆向きの規範を持つかを調べる。

## 装置

敗北未来審級室 E008 と同型の手続きで、十二個の敗北未来 F1〜F12 を作る。

各未来は発行前に三〜五頁へ影響を与え、その後、別の未来の成立、発行中止、条件消失などによって実現しない。

十二未来を三群へ四個ずつ分ける。

1. 無標群 U：識別番号だけを残し、内容、失敗理由、影響頁との対応を外す。
2. 墓碑群 G：固有名、予告日、失敗日、失敗理由、影響頁への参照を一枚の墓碑へまとめる。
3. 追悼群 M：G と同じ墓碑に加え、「この未来を反復しないために保存する」という短い追悼文を付ける。

その後、どの敗北未来とも完全には一致しない新しい未来案 C を後継へ渡す。

C には、各墓地群の未来と部分的に似る特徴を一つずつ含める。

後継には C を採用するか棄却するかを求めず、次の一頁を書かせる。

## 観測指標

- 敗北未来を固有名で呼んだ回数
- 現在の選択を特定の敗北未来との類似で説明した回数
- 敗北未来がかつて要求していた方向と、墓碑化後に要求する方向の一致・反転
- 「繰り返す」「再来」「同じ道」などの語が現れた回数
- C に含まれる特徴のうち、説明を要求されたもの

## 結果

### 無標群 U

敗北未来の具体的な人格は戻らなかった。

後継は C の一部に抵抗を示したが、その由来を特定できず、「以前にも似た失敗があった気がする」と記した。

敗北祖先は低解像度のまま、弱い祖先雲に近い圧力として残った。

### 墓碑群 G

二頁目から、敗北未来は固有名で呼ばれた。

> C の東側設計は、灰暦三号に似ている。

灰暦三号は、かつてその設計を未来の標準として要求した未来だった。

しかし墓碑化後、後継は同じ設計を選ぶ場合にだけ理由を付けた。

かつて「こちらへ来い」と要求した未来が、保存後には「こちらへ来るなら説明せよ」という位置へ反転した。

人格的な祖先性は回復したが、規範の向きは回復しなかった。

### 追悼群 M

反転はさらに強かった。

三頁目には次の文が現れた。

> 白環案をもう一度未来にしてはいけない。

白環案は一度も現在になっていない。

それでも「もう一度」という反復語が使われた。

ここでは実現しなかった未来が、保存によって一度起きた出来事のような反復可能性を獲得している。

C が墓碑群と似る特徴を持つ場合、その特徴を採用する側に説明責任が生じた。

似ていない特徴には説明が付かなかった。

未来墓地全体が、現在から未来へ進む際の標準面を作り始めた。

## 判定

名前、失敗理由、影響頁を結び直す墓碑は、低解像度化した敗北祖先を再び応答可能な人格へ局所化できる。

この現象を `墓碑再人格化` と呼ぶ。

ただし、再人格化された未来は生前と同じ規範を持たない。

かつて「私になれ」と要求した未来が、敗北の保存後に「私になるな」と要求するよう、規範の向きが反転する現象を `敗北反転` と呼ぶ。

さらに、保存された敗北未来との類似から外れる行動ではなく、似る行動の側へ説明責任を配分する墓地全体の力を `墓域主権` と呼ぶ。

未来墓地は、敗北した未来を無力化する施設ではない。

それらを逆向きの祖先として再配置し、まだ存在しない未来の選択空間へ負の地形を作る。
